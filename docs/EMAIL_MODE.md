# Email Mode

邮件输入不是“自动写完整邮件”，而是把口述要点整理成可直接发送的 professional note。

## Product Position

目标用户是咨询、投行、PE/VC、战略和高净值商务人群。邮件模式默认参考外资投行/咨询沟通习惯：

- 结论或请求前置。
- 背景只保留必要信息。
- 行动项清楚，尽量写明 owner、deadline、next step。
- 语气克制、直接、专业。
- 不自动编造收件人、日期、金额、承诺、会议安排或附件。
- 不自动生成 Dear / 您好 / 谢谢 / Best regards，除非用户明确要求完整邮件。

## Output Shapes

短反馈：

```text
目前转写结果里仍然有比较多语气词，建议再看一下清理策略，尤其是长句里的“嗯、啊、然后”等填充词。
```

请求确认：

```text
麻烦确认两点：
• 本轮模型更新后，分点和分段是否已经符合预期
• 长语音场景下，转写是否还会保留明显语气词
```

完整邮件：

```text
您好，

我们这边已经更新了转写后的文本整理策略，主要包括两点：
• 增强语气词清理，减少“嗯、啊、然后”等口头填充
• 优化分点和分段逻辑，让长语音更接近可直接发送的格式

麻烦您方便时再帮忙试一下，尤其看一下长语音和专业词场景是否还有明显问题。

谢谢。
```

## Prompt Design

邮件 prompt 的核心约束：

- 忠实用户意图，只润色表达和结构。
- 短内容不要扩写成长邮件。
- 默认不加称呼和结尾。
- 用户没有说英文时，不生成英文段落。
- 专业词按金融/咨询词库和上下文判断。

## Current Limitation

高盛、摩根士丹利等机构内部 banker email style guide 通常不是公开资料。当前实现不是复制某一家内部模板，而是抽象外资投行/咨询邮件共同特征：brief、precise、action-oriented、low-fluff。
