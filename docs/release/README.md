# 墨声 Alpha 测试版

墨声是一个 Windows 本地语音输入工具：输入 API Key 后，按一次快捷键开始说话，再按一次结束，随后文字会进入当前光标位置。

这是早期 alpha 测试版。请先在不重要的输入框里试用，比如记事本、浏览器搜索框、微信草稿框。

## 快速开始

1. 双击 `Mosheng.exe`。
2. 在设置窗口输入智谱 API Key。这个 Key 同时用于语音识别与智能排版。
3. 点击保存。
4. 默认按一下 Ctrl + Space 开始说话，再按一下 Ctrl + Space 结束并自动输入。
5. 右下角托盘图标可以重新打开设置或退出。

## 反馈重点

- 能不能稳定打开。
- API Key 能不能保存。
- 按一下开始、再按一下结束是否顺手。
- 识别结果是否能进入当前光标。
- 30 秒以上语音是否失败。
- 悬浮胶囊是否舒服、是否打扰。
