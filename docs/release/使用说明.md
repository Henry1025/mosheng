# 使用说明

## 启动

双击 `Mosheng.exe`。启动后会出现设置窗口，也会在系统托盘常驻。

## 设置 API Key

在 `智谱 API Key` 输入框粘贴你的智谱 API Key，然后点击保存。这个 Key 同时用于语音识别与智能排版；保存成功后，输入框里会显示已保存信号，不会明文展示密钥。

API Key 只保存在当前 Windows 用户的系统安全区。

## 语音输入

默认快捷键是 Ctrl + Space：

1. 把光标放到你要输入的位置。
2. 按一下 Ctrl + Space，墨声开始收音。
3. 说话。
4. 再按一下 Ctrl + Space，墨声停止收音并进入 Thinking Mode。
5. 看到对勾后，文字会自动输入到当前光标位置。

## 修改快捷键

点击设置窗口里的 `更改`，然后按下想使用的键或组合键。

示例：

- 左 Shift
- Alt
- Ctrl + Space
- Ctrl + Alt + M

如果只想用单个修饰键，比如左 Shift，按下后松开即可确认。

## 退出

在系统托盘找到墨声图标，右键选择退出。
