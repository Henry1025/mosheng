# 墨声 Alpha 灰度测试

目标：先验证 Windows 本地语音输入是否真的顺手、稳定、可解释，再考虑安装器、官网和更大范围传播。

## 推荐节奏

1. 本机自测 1 天。
2. 发给 3-5 个熟人测试。
3. 收集 20-30 条真实反馈后，再发第二个 alpha 包。

## 首轮测试人群

- 每天在 Windows 上写字的人：微信、飞书、浏览器、Notion、Office。
- 能接受手动填 API Key。
- 愿意把失败场景说清楚，而不是只说“不能用”。

## 必测场景

- 首次打开，填写 API Key，保存后重启。
- 更改唤醒快捷键，包括单键和组合键。
- 在微信、飞书、浏览器输入框、记事本里输入。
- 5 秒、30 秒、60 秒语音。
- 识别失败、网络失败、API Key 错误。
- 按一次开始、再按一次结束；误触发、不想输入、切换窗口。
- 高 DPI 屏幕和多显示器。

## 发包建议

使用 GitHub Release 发布 zip，而不是直接发送裸 exe。

包名格式：

```text
Mosheng-v0.1.0-alpha.1-windows-x64.zip
Mosheng-v0.1.0-alpha.2-windows-x64.zip
```

每次包里都带：

- `Mosheng.exe`
- `README.md`
- `使用说明.md`
- `反馈模板.md`
- `已知问题.md`
- `VERSION.txt`

## 反馈问题优先级

- P0：打不开、闪退、不能保存 API Key、无法退出。
- P1：识别经常失败、输入到错误位置、快捷键冲突、长语音失败。
- P2：UI 粗糙、动效不顺、提示不清楚。
- P3：功能建议。
